# 二叉堆

二叉堆是一棵**完全二叉树**，并且满足堆序：本例使用**小顶堆**，任意节点的值都不大于它的孩子，因此根节点始终是当前最小值。完全二叉树可以紧凑地存进数组：下标 `i` 的父节点是 `(i - 1) / 2`，左孩子是 `2i + 1`，右孩子是 `2i + 2`。插入时把新值放到数组末尾再向上调整，删除堆顶时把末元素移到根再向下调整，两种操作都只走一条根到叶的路径，复杂度为 `O(log n)`。

## 输入格式

输入是一组依次插入的值，逗号或空格分隔。建堆采用逐个插入并上浮的方式，所以输入顺序会影响中间过程，但最终数组一定满足小顶堆性质。

默认输入：

```text
50, 30, 70, 20, 40, 60, 80
```

逐值插入后的数组变化：

```text
50             [50]
30             [30, 50]
70             [30, 50, 70]
20             [20, 30, 70, 50]
40             [20, 30, 70, 50, 40]
60             [20, 30, 60, 50, 40, 70]
80             [20, 30, 60, 50, 40, 70, 80]
```

默认最终堆：

```text
          20
        /    \
      30      60
     /  \    /  \
   50   40  70   80

数组下标：0    1    2    3    4    5    6
数组值：  20   30   60   50   40   70   80
```

规则：

- 至少要有 1 个值，最多 15 个节点。
- 每个值都是 -999 到 999 的整数。
- 允许重复值；相等时不再上浮或下沉，动画用节点 id 区分相同的值。
- 插入的目标值同样必须是 -999 到 999 的整数。
- 删除堆顶不需要目标值；在单节点堆上删除后得到空堆。

常见错误：

| 情况 | 提示 |
| --- | --- |
| 空输入 | 请输入键序列，例如 `50, 30, 70, 20, 40, 60, 80`。 |
| 非整数或越界 | 请输入最多 15 个整数，范围 -999 到 999。 |
| 插入值非法 | 插入值须为 -999 到 999 的整数。 |
| 插入超过上限 | 最多展示 15 个节点，无法继续插入。 |

## 默认结果

默认操作是「插入」，目标值为 `15`。

| 操作 | 路径 / 结果 | 帧数 |
| --- | --- | --- |
| 创建 | 依次插入 7 个值，含追加、比较与上浮交换 | 19 |
| 插入 15 | 追加到下标 7，依次与 50、30、20 交换，成为新根 | 8 |
| 插入 100 | 追加到下标 7，与父节点 50 比较后停止 | 3 |
| 插入 20 | 与 50、30 交换，遇到相等的根 20 后停止 | 7 |
| 删除堆顶 | 20 被删除，末元素 80 移到根，再与 30、40 交换 | 6 |
| `10, 20, 30` 删除堆顶 | 30 移到根，与 20 交换 | 4 |
| `10, 100, 20` 删除堆顶 | 20 移到根，已经小于 100，停止下沉 | 3 |
| `50` 删除堆顶 | 唯一节点删除，堆变空 | 2 |

删除默认堆顶后的数组为 `[30, 40, 60, 50, 80, 70]`，根从 20 变为 30。

## 画面语义

| 状态 | 颜色 | 含义 |
| --- | --- | --- |
| 未访问 | 灰色 | 还没有进入当前调整路径 |
| 当前节点 / 当前下标 | 琥珀色 | 本帧正在上浮或下沉的节点，树节点与数组格同步高亮 |
| 已比较 | 蓝色 | 当前调整路径上已经比较过的节点 |
| 父子边 | 蓝色高光 | 孩子节点在当前帧被访问后，它与父节点的连线高亮 |
| 数组下标 | 灰色小字 | 画在每个数组格上方，从 0 开始 |

画面上半部分是堆的完全二叉树，下半部分是按相同顺序排列的数组。树节点和数组格使用同一套节点 id，所以交换时树节点会移动，数组值也会同步换位；当前节点在两边同时变成琥珀色。

## 帧模型

- **创建**：对每个输入值先发追加帧，再沿父节点链发比较帧；需要交换时发交换帧，直到堆序满足。默认共 19 帧。
- **插入**：准备帧 + 追加帧 + 上浮比较/交换帧，最后一帧说明插入完成。
- **删除堆顶**：准备帧 + 末元素移到堆顶帧 + 下沉比较/交换帧，最后一帧说明删除完成。
- 最后一帧的旁白说明结果，不再单独增加完成帧。
- 每帧包含节点、父子边、数组顺序、根身份、当前节点、已访问节点、旁白和代码锚点；调用栈和队列为空。
- 切换操作或应用新输入后回到第 0 帧。

操作下拉顺序是创建、插入、删除堆顶；默认选中插入，进入页面时先看到完整堆与准备帧。

## 三种操作

### 创建

按输入顺序逐个插入：把值放到数组末尾，然后与父节点比较；小于父节点就交换，直到到达根或父节点不大于它。

```text
build(keys):
    heap = empty array
    for value in keys:
        heap.append(value)
        i = len(heap) - 1
        while i > 0:
            parent = (i - 1) // 2
            if heap[parent] <= heap[i]:
                break
            swap(heap[parent], heap[i])
            i = parent
    return heap
```

- 追加帧锚点 `append`，旁白：`把 X 放到数组下标 i。`
- 比较帧锚点 `compare`，需要上浮时旁白：`比较 X 与父节点 Y：X < Y，需要上浮。`；不需要交换时旁白：`比较 X 与父节点 Y：X >= Y，堆序满足，停止上浮。`
- 交换帧锚点 `swap`，旁白：`交换 X 与 Y，X 上浮到下标 i。`
- 最后一个交换或比较帧追加：`建堆完成，共 n 个节点。`
- 空堆的第一个值直接成为根，只发追加帧。

### 插入

插入等价于在数组末尾追加后执行一次上浮。若新值不小于父节点，立即停止。

```text
insert(heap, value):
    heap.append(value)
    i = len(heap) - 1
    while i > 0:
        parent = (i - 1) // 2
        if heap[parent] <= heap[i]:
            break
        swap(heap[parent], heap[i])
        i = parent
```

- 准备帧锚点 `start`，旁白：`准备插入 X：把 X 追加到数组末尾。`
- 追加、比较、交换帧同创建。
- 最后一帧追加：`插入完成，共 n 个节点。`
- 默认插入 15：`start`、`append(15)`、`compare(50)`、`swap`、`compare(30)`、`swap`、`compare(20)`、`swap`。
- 表已有 15 个节点时，再插入新值会报错；插入已存在的值仍然允许，相等时停在父节点处。

### 删除堆顶

删除堆顶时，先记录根值，再把数组最后一个元素移到根并缩短数组，然后从根开始向下调整。

```text
extract_min(heap):
    minimum = heap[0]
    last = heap.pop()
    if len(heap) == 0:
        return minimum
    heap[0] = last
    i = 0
    while True:
        left = 2 * i + 1
        if left >= len(heap):
            break
        child = left
        if left + 1 < len(heap) and heap[left + 1] < heap[left]:
            child = left + 1
        if heap[i] <= heap[child]:
            break
        swap(heap[i], heap[child])
        i = child
    return minimum
```

- 准备帧锚点 `start`，旁白：`准备删除堆顶：记录堆顶 X，把末元素 Y 移到堆顶。`
- 移动末元素帧锚点 `replace`，旁白：`把末元素 Y 移到堆顶，堆大小变为 n。`
- 比较帧锚点 `compare`：先选出较小的孩子；需要下沉时旁白：`比较 X 与较小孩子 Y：X > Y，需要下沉。`；否则旁白：`比较 X 与较小孩子 Y：X <= Y，堆序满足，停止下沉。`
- 交换帧锚点 `swap`，旁白：`交换 X 与 Y，X 下沉到下标 i。`
- 最后一帧追加：`删除完成，当前堆顶为 X。`；堆为空时写 `删除完成，堆为空。`
- 单节点堆只有准备帧与移动末元素帧；末元素就是被删除的节点，数组直接变空。
- 默认删除：`start`、`replace(80)`、`compare(30)`、`swap`、`compare(40)`、`swap`。

## 布局与边界

- 上半部分是完整二叉树：按数组下标确定深度与横向位置，根在最上层；节点为圆形，直径固定为 36。
- 树区域从舞台顶部到数组上方，最大深度由整段 trace 的最大节点数决定，步进时不会改变。
- 下半部分是数组格：宽 32、高 22，格间距 4，下标显示在格子上方。
- 数组格按当前堆大小居中；节点增多时整行向左扩展，但画布宽度按整段最大节点数固定。
- 舞台高度固定为 208；默认 7 个节点时宽度 430，15 个节点时宽度 572，超出可用宽度时横向滚动。
- 节点 id 在整段 trace 内稳定；交换时树节点沿轨迹移动，数组格同步更新值。
- 空堆仍显示“空堆”提示，不绘制数组格。
- 删除堆顶后，旧根消失，末元素移动到根；原末元素位置的数组格被移除。

## 边界与测试

- 单节点：创建、插入、删除堆顶后空堆。
- 重复值：`10, 10` 插入时相等不交换；删除堆顶后剩余节点仍满足堆序。
- 上浮一直到达根：默认插入 15。
- 上浮立即停止：默认插入 100。
- 下沉到叶子、下沉一步即停止，以及只有单节点、两节点、三节点的情况。
- 15 个节点时插入新值报错；15 个节点仍能正常删除堆顶。
- 空输入、非整数、越界与非法插入值。
- 每个操作每一帧的锚点都必须在六种语言模板中存在；代码显示文本不能残留 `@anchor`。
- 场景几何测试覆盖树节点不碰撞、数组格不重叠、下标与值绑定正确、空堆提示，以及所有帧尺寸稳定。

## 实现约定

- 堆按数组顺序保存节点；节点 id 按首次插入顺序从 0 开始分配，交换不改变 id，删除不回收 id。
- 每帧写入 `heapOrder`：数组下标到节点 id 的映射，长度为当前堆大小。
- `items` 按 id 升序排列，因此 **`active` / `settled` 是 items 下标**；`heapOrder`、`links` 与 `rootId` 使用节点 id。
- `links` 的第三项标记 `"left"` / `"right"`；只包含当前存在的父子边。
- 空堆用 `items: []`、`heapOrder: []`、`rootId: null`。
- 操作 `create`、`insert`、`extract` 与代码模板键一致。
- 数组表示与树表示共享同一份顺序，场景不自行重排节点。
