# 二叉搜索树

二叉搜索树（BST）满足：任意节点的左子树值都小于它，右子树值都大于它。查找、插入与删除都从根出发，按大小关系选择方向；删除时先找到目标，再根据孩子数量修改结构。平均复杂度为 `O(log n)`，最坏退化为链时为 `O(n)`。

## 输入格式

输入是一组依次插入的值，逗号或空格分隔。界面会按顺序建树，因此同一组值换一个顺序，树的形状可能不同。

默认输入：

```text
50, 30, 70, 20, 40, 60, 80
```

对应的树：

```text
        50
      /    \
    30      70
   /  \    /  \
 20   40  60   80
```

规则：

- 至少要有 1 个值，最多 15 个节点。
- 每个值都是 -999 到 999 的整数。
- 插入序列内不允许重复值；需要演示重复插入时，使用「插入」操作并输入已存在的目标值。
- 目标值同样必须是 -999 到 999 的整数。

常见错误：

| 情况 | 提示 |
| --- | --- |
| 空输入 | 请输入插入序列，例如 `50, 30, 70, 20, 40, 60, 80`。 |
| 非整数或越界 | 请输入最多 15 个整数，范围 -999 到 999。 |
| 重复值 | 插入序列包含重复值 X，二叉搜索树不接受重复节点。 |
| 目标值非法 | 目标值须为 -999 到 999 的整数。 |
| 插入超过上限 | 最多展示 15 个节点，无法继续插入。 |

查找未命中、删除未命中、插入已存在的值都不是输入错误，动画会在最后一帧说明结果。

## 默认结果

默认目标值为 `40`。

| 操作 | 路径 / 结果 | 帧数 |
| --- | --- | --- |
| 创建 | 依次插入 7 个值，含每次插入的比较路径 | 17 |
| 查找 40 | `50 → 30 → 40`，命中 | 4 |
| 查找 35 | `50 → 30 → 40`，左孩子为空，未找到 | 4 |
| 插入 35 | `50 → 30 → 40`，在 40 左侧创建 35 | 5 |
| 插入 40 | `50 → 30 → 40`，值已存在，不插入 | 4 |
| 删除 40 | 命中后按叶子节点删除 | 5 |
| 删除 30 | 命中后取右子树最小值 40，复制后继并删除 40 | 6 |
| 删除 35 | 未找到，删除取消 | 4 |

其他常见删除：

| 输入 / 操作 | 情形 | 结果 |
| --- | --- | --- |
| `50, 30, 20`，删除 30 | 只有一个左孩子 | 20 接替 30，成为 50 的左孩子 |
| `50, 30`，删除 50 | 根只有一个孩子 | 30 成为新的根 |
| `50`，删除 50 | 唯一节点 | 空树 |
| 默认树，删除 50 | 根有两个孩子 | 后继 60 复制到根，再删除 60 |

## 画面语义

| 状态 | 颜色 | 含义 |
| --- | --- | --- |
| 未访问 | 灰色 | 还没有进入比较路径 |
| 当前 | 琥珀色 | 本帧正在比较或修改的节点 |
| 已访问 | 蓝色 | 搜索路径上已经比较过的节点 |
| 父边 | 蓝色高光 | 子节点在当前帧被访问后，它与父节点的连线高亮 |
| 目标徽章 | 琥珀色小徽章 | 文本为 `target = 值`，跟随当前节点移动 |

目标徽章只在有当前节点的查找/插入比较帧和插入结果帧显示：

- 位于当前节点右上方；靠近画布右边界时自动翻到左上方。
- 连续比较时，徽章从上一个当前节点滑到下一个当前节点。
- 准备帧没有当前节点，不显示徽章。
- 删除的后继、复制、删除帧不显示徽章，避免把后继或父节点误认为搜索目标。
- 固定 208 高度内，徽章可能与父子边或相邻节点局部重叠；它保证不超出画布。

## 帧模型

- **创建**：对每个插入值，先发搜索路径上的比较帧，再发插入帧。第一个值只发根节点插入帧；默认序列共 17 帧。
- **查找**：第一帧是准备帧，之后每个被比较的节点一帧；最后一帧是命中或未命中。
- **插入**：准备帧，加搜索路径比较帧，最后一帧是新建节点或“已存在”。
- **删除**：准备帧，加搜索路径帧；命中后根据叶子 / 单孩子 / 双孩子追加修改帧；未命中时以“删除取消”结束。
- 最后一帧的旁白说明“完成”或结果，不再单独增加完成帧。
- 每帧包含节点、父子边、根身份、当前节点、已访问节点、目标值、旁白、代码锚点；调用栈和队列为空。
- 切换操作或应用新输入后回到第 0 帧。

操作下拉顺序是创建、查找、插入、删除；默认选中查找，进入页面时先看到完整树的准备帧。

## 四种操作

### 创建

按输入顺序逐个插入：每个值从根开始比较，小于当前值走左边，大于走右边，直到空位；在空位创建节点。空树时第一个值直接成为根。

```text
insert(root, value):
    if root == null:
        return new TreeNode(value)
    node = root
    while node != null:
        if value == node.value:
            return root
        if value < node.value:
            if node.left == null:
                node.left = new TreeNode(value)
                return root
            node = node.left
        else:
            if node.right == null:
                node.right = new TreeNode(value)
                return root
            node = node.right
```

- 比较帧锚点 `compare`，旁白：`插入 X：X < Y，进入左子树。`（大于时写右子树）
- 插入帧锚点 `insert`；根节点旁白：`创建根节点 X。`；孩子旁白：`在 P 的左子树创建 X。`（右子树同理）
- 最后一个插入帧追加：`建树完成，共 n 个节点。`
- 创建过程中已有节点会平滑移动到新的中序位置，当前部分树整体居中。

### 查找

从根开始比较：相等就命中；小于走左子树，大于走右子树；走到空位说明未找到。

```text
search(root, target):
    node = root
    while node != null:
        if target == node.value:
            return node
        node = target < node.value ? node.left : node.right
    return null
```

- 准备帧锚点 `start`，旁白：`准备查找 X：从根节点开始比较。`
- 比较帧锚点 `compare`，旁白：`比较 X 与 Y：X < Y，进入左子树。`
- 命中帧锚点 `found`，旁白：`比较 X 与 Y：相等，找到目标节点。`
- 未命中帧锚点 `miss`，旁白：`比较 X 与 Y：X < Y，左孩子为空，未找到。`
- 查找 40 的 active 顺序是 `50 → 30 → 40`；查找 35 在 40 处停止并报告未找到。

### 插入

插入先按查找的走法找到位置；如果值已存在则不重复插入，否则在空位创建节点。

- 准备帧锚点 `start`，旁白：`准备插入 X：先沿搜索路径找到空位。`
- 路径帧锚点 `compare`。
- 已存在帧锚点 `exists`，旁白：`比较 X 与 Y：相等，值已存在，不重复插入。`
- 插入帧锚点 `insert`，旁白：`在 P 的左子树创建 X。插入完成，共 n 个节点。`
- 默认插入 35：`start`、`compare(50)`、`compare(30)`、`compare(40)`、`insert(35)`。

### 删除

删除严格先搜索，再修改节点。未找到时不做任何结构修改。

```text
delete(root, target):
    node = search(root, target)
    if node == null:
        return root
    if node.left == null:
        return replace(node, node.right)   # 叶子也走这里
    if node.right == null:
        return replace(node, node.left)
    successor = minimum(node.right)
    node.value = successor.value
    node.right = delete(node.right, successor.value)
    return root
```

三种情形：

1. **叶子**：直接移除。锚点 `leaf`，旁白：`X 是叶子节点，直接删除。删除完成。`
2. **只有一个孩子**：让孩子接替自己的位置。锚点 `one_child`，旁白：`X 只有一个孩子，用 Y 接替。删除完成。`
3. **两个孩子**：
   - 在右子树一路向左找到最小值（中序后继）。锚点 `successor`，旁白：`X 有两个孩子，右子树最小节点是 Y。`
   - 把后继值复制进目标节点。锚点 `copy`，旁白：`把 Y 写入 X 所在节点。`
   - 删除后继节点。后继没有左孩子，可能有一个右孩子；用它的右孩子接替。锚点 `remove`，旁白：`删除后继节点 Y。删除完成。`

删除根时同步更新根身份：叶子删除后为空树，单孩子删除后由孩子成为新根，双孩子删除后根节点 id 不变。

- 默认删除 40：`start`、`compare(50)`、`compare(30)`、`found(40)`、`leaf`。
- 默认删除 30：`start`、`compare(50)`、`found(30)`、`successor(40)`、`copy`、`remove`。
- 未命中时最后锚点 `miss`，旁白：`未找到 X，删除取消。`

## 代码锚点

代码面板提供 C / C++ / Python / Go / Java / Rust 六个版本，所有语言共用同一组行尾锚点。节点结构假定已定义。

| 操作 | 帧使用的锚点 | 模板中包含的锚点 |
| --- | --- | --- |
| 创建 | `compare`、`insert` | `start`、`compare`、`insert`、`done` |
| 查找 | `start`、`compare`、`found`、`miss` | `start`、`compare`、`found`、`miss`、`done` |
| 插入 | `start`、`compare`、`insert`、`exists` | `start`、`compare`、`insert`、`exists`、`done` |
| 删除 | `start`、`compare`、`found`、`miss`、`leaf`、`one_child`、`successor`、`copy`、`remove` | 上述全部 + `done` |

未知操作回退到查找模板。

## 布局与徽章

- x 坐标：对树做中序遍历，每个节点占一个 rank 槽位。
- y 坐标：按深度分行；根在最上层。
- 节点为圆形，直径随整段演示的最大深度自适应；舞台高度固定为 208。
- 画布宽度由整段演示的最大节点数决定，步进时不会改变。
- 节点 id 在整段 trace 内稳定；插入和删除导致的中序 rank 变化会让已有节点平滑移动。
- 创建过程中的部分树会整体居中；节点大小、槽宽和行距保持不变。
- 目标徽章文本为 `target = 值`，字号 11、高度 20；默认放在当前节点右上方。
- 徽章右侧会越界时翻到节点左上方，并夹在画布边界内；允许与连线或节点局部重叠。
- 深树节点会缩小；演示时建议使用平衡序列或较少的节点。

## 边界与测试

- 单节点：`50`，分别验证查找命中/未命中、删除后空树。
- 只有左孩子、只有右孩子：验证单孩子删除后的父子边和根更新。
- 删除根：叶子、单孩子、双孩子三种情况都要验证 `rootId`。
- 双孩子删除：验证右子树最小节点、复制后的重复值帧、删除后继后的最终树。
- 15 个节点的链状树：验证节点不重叠、不越界；再插入新值时报错。
- 重复输入、空输入、目标值越界、插入超过 15 个节点。
- 每个操作每一帧的锚点都必须在六种语言模板中存在；代码显示文本不能残留 `@anchor`。
- 场景几何测试覆盖创建、查找、插入、三种删除和空树；徽章在所有采样时刻不越界，并绑定当前 active 节点。

## 实现约定

- 节点 id 按插入顺序从 0 开始分配；删除不回收 id，插入继续递增，保证跨帧身份稳定。
- `items` 按 id 升序排列，因此 **`active` / `settled` 是 items 下标**；`links` 与 `rootId` 使用节点 id。
- `links` 的第三项标记 `"left"` / `"right"`；只包含当前存活节点。
- `Frame.target` 只在需要显示目标徽章时设置；数组/链表场景忽略该字段。
- 删除后继时，后继没有左孩子，可能有一个右孩子；改接时同步父指针。
- 空树用 `items: []`、`rootId: null`，场景显示“空树”。
- 操作 `create`、`search`、`insert`、`delete` 与代码模板键一致。
- 工作台按整段 trace 的最大深度传入 `treeDepth`，保持节点直径与行距稳定。
