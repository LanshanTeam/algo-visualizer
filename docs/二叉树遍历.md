# 二叉树遍历

二叉树遍历专题用前序序列还原一棵二叉树，再分别演示创建、前序、中序、后序与层序遍历。四种遍历的时间复杂度都是 `O(n)`，额外空间为 `O(n)`（递归栈或队列）。

## 输入格式

输入是一棵二叉树的前序序列，按「根、左子树、右子树」的顺序书写，逗号或空格分隔。`#` 表示空子树；它只占一个记号，不再继续展开。

默认输入：

```text
1, 2, 4, #, #, 5, #, #, 3, 6, #, #, 7, #, #
```

对应的树：

```text
        1
      /   \
     2     3
    / \   / \
   4   5 6   7
```

规则：

- 根不能是 `#`；至少要有 1 个节点。
- 序列必须正好用完：每个非空节点都要有两个孩子位置，缺失的一侧写 `#`。
- 最多 15 个节点（31 个记号）；节点值为 -999 到 999 的整数。
- 只有右孩子的节点写 `值, #, 右孩子`，不要省略左孩子的 `#`。

常见错误：

| 情况 | 提示 |
| --- | --- |
| 空输入 | 请输入前序序列，例如 `1, 2, #, #, 3, #, #`。 |
| 无法识别的记号 | 无法识别记号 `X`，请使用整数或 `#`。 |
| 值越界 | 节点值须为 -999 到 999 的整数。 |
| 超过规模 | 最多展示 15 个节点，请减小输入规模。 |
| 序列不足 | 前序序列不完整：请为每个节点补齐左右孩子（用 `#` 表示空）。 |
| 序列多余 | 前序序列有多余记号：请检查 `#` 的数量。 |
| 根为空 | 根节点不能为空。 |

深度较大的树会在固定高度内自动缩小节点；演示时建议使用平衡树或节点较少的输入。

## 默认树的预期结果

| 遍历 | 顺序 | 结果 |
| --- | --- | --- |
| 前序 | 根 → 左 → 右 | `1 2 4 5 3 6 7` |
| 中序 | 左 → 根 → 右 | `4 2 5 1 6 3 7` |
| 后序 | 左 → 右 → 根 | `4 5 2 6 7 3 1` |
| 层序 | 逐层，从左到右 | `1 2 3 4 5 6 7` |

## 画面语义

| 状态 | 颜色 | 含义 |
| --- | --- | --- |
| 未访问 | 灰色 | 还没有被遍历到 |
| 当前 | 琥珀色 | 本帧刚访问的节点 |
| 已访问 | 蓝色 | 之前帧已经访问过 |
| 父边 | 蓝色高光 | 子节点被访问后，它与父节点的连线高亮 |

当前节点不额外画 `curr` 指针；琥珀色和旁白足以标识它，也能避免深树中标注与父子边互相遮挡。

创建操作的节点还没有进入遍历，因此已创建的节点保持灰色，只有最新创建的节点是琥珀色，连接它的父边高亮。切换到任一遍历操作后，准备帧会把所有节点恢复为灰色。

## 帧模型

- **创建**：每个非空节点一帧，按前序递归顺序创建，共 `n` 帧。
- **前序 / 中序 / 后序 / 层序**：第一帧是准备帧，之后每访问一个节点一帧，共 `n + 1` 帧。
- 最后一帧的旁白说明“遍历完成”，不再单独增加完成帧。
- 播放条显示 `当前帧 / 总帧数`；切换操作或应用新输入后回到第 0 帧。
- 每帧包含节点、父子边、根身份、当前节点、已访问节点、旁白、代码锚点，以及递归栈或队列。

操作下拉的顺序是创建、前序、中序、后序、层序；默认选中前序，进入页面时先看到完整树的准备帧。

## 五种操作

### 创建二叉树

按前序序列递归建树：读取一个记号；如果是 `#` 就返回空；否则创建节点，再依次递归左子树和右子树。

```text
build():
    token = next()
    if token == #:
        return null
    node = new TreeNode(token)
    node.left = build()
    node.right = build()
    return node
```

- 第一帧是根节点，锚点 `root`。
- 左孩子帧锚点 `left`，右孩子帧锚点 `right`。
- 旁白：`读取 v，创建根节点。` / `读取 v，作为 p 的左孩子。` / `读取 v，作为 p 的右孩子。`
- 最后一帧追加：`建树完成，共 n 个节点。`
- 递进过程中已有节点会平滑移动到新的中序位置；当前帧整体居中。

### 前序遍历

访问顺序是「根 → 左 → 右」：进入节点时先访问，再递归左右子树。

```text
preorder(node):
    if node == null: return
    visit(node)
    preorder(node.left)
    preorder(node.right)
```

- 准备帧锚点 `start`，旁白：`准备前序遍历：顺序为「根 → 左 → 右」。`
- 访问帧锚点 `visit`，旁白：`访问 v，然后递归左子树、右子树。`
- 调用栈显示当前递归路径，例如 `preorder(1) → preorder(2) → preorder(4)`。
- 最后一帧追加：`前序遍历完成。`

### 中序遍历

访问顺序是「左 → 根 → 右」：左子树处理完后才访问节点，再递归右子树。

```text
inorder(node):
    if node == null: return
    inorder(node.left)
    visit(node)
    inorder(node.right)
```

- 准备帧旁白：`准备中序遍历：顺序为「左 → 根 → 右」。`
- 访问帧旁白：`左子树处理完，访问 v，然后递归右子树。`
- 调用栈显示当前递归路径，例如 `inorder(1) → inorder(2) → inorder(4)`。
- 最后一帧追加：`中序遍历完成。`

### 后序遍历

访问顺序是「左 → 右 → 根」：左右子树都处理完后才访问节点。

```text
postorder(node):
    if node == null: return
    postorder(node.left)
    postorder(node.right)
    visit(node)
```

- 准备帧旁白：`准备后序遍历：顺序为「左 → 右 → 根」。`
- 访问帧旁白：`左右子树处理完，访问 v。`
- 调用栈显示当前递归路径，例如 `postorder(1) → postorder(2) → postorder(4)`。
- 最后一帧追加：`后序遍历完成。`

### 层序遍历

用队列逐层访问：根先入队；每次出队一个节点，访问后再把它的左右孩子依次入队。

```text
levelorder(root):
    if root == null: return
    queue.push(root)
    while queue not empty:
        node = queue.popFront()
        visit(node)
        if node.left: queue.push(node.left)
        if node.right: queue.push(node.right)
```

- 准备帧：根入队，旁白：`准备层序遍历：根节点 r 入队，逐层访问。`
- 访问帧：`出队 v，访问；左/右孩子入队。` 没有孩子时用 `出队 v，访问；没有孩子入队。`
- 队列行显示入队后的剩余队列；没有递归栈。
- 最后一帧队列为空，旁白追加：`层序遍历完成。`

## 布局与动画

- x 坐标：对树做中序遍历，每个节点占一个 rank 槽位。
- y 坐标：按深度分行；根在最上层。
- 节点为圆形，直径随整段演示的最大深度自适应；舞台高度固定为 208。
- 画布宽度由整段演示的最大节点数决定，步进时不会改变。
- 创建过程中的部分树会整体居中；节点大小、槽宽和行距保持不变。
- 遍历帧只有颜色变化，不产生位移；创建帧会平滑移动已有节点。
- 减少动态效果时直接呈现目标帧。

## 边界与测试

- 单节点：`1, #, #`。
- 只有右孩子：`1, #, 2, #, #`，节点必须画在父节点右侧。
- 只有左孩子：`1, 2, #, #, #`。
- 左斜/右斜树：验证节点不重叠、不越界。
- 15 个节点的链状树：验证页面仍固定高度，节点缩小但不重叠。
- 非法序列：未知记号、序列不足、序列多余、根为空、超过 15 个节点。
- 每个操作每一帧的锚点都必须在六种语言模板中存在；代码显示文本不能残留 `@anchor`。

## 实现约定

- 节点 id 按前序顺序从 0 开始分配，`items` 也按前序排列，因此 `id` 等于 `items` 下标；`rootId = 0`。
- `Frame.links` 的第三项标记 `"left"` / `"right"`，保证只有右孩子时不会被误认为左孩子。
- 输入解析内部用 `NaN` 作为 `#` 的哨兵；`NaN` 不会进入 `items`，共享的 `parseValues` 不受影响。
- 工作台按整段 trace 的最大深度传入 `treeDepth`，用于稳定节点直径与行距。
- 操作 `create`、`preorder`、`inorder`、`postorder`、`levelorder` 与代码模板键一致。
